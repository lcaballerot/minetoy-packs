# Packs de Bedrock (Geyser)

Se sirven por CDN (jsDelivr sobre esta rama) desde `resource-pack-urls` del Geyser del proxy.

- `minetoy_iconos.mcpack` 1.0.12: glifos U+E9xx (iconos de texto + insignias de rango U+E9A0–E9B2, RGB U+E9C0–E9C9).
  `glyph_E9.png` 2048×2048 (celdas de 128 px; Bedrock dibuja 1 px = 1 unidad y centra la celda en la línea).

URL: https://cdn.jsdelivr.net/gh/lcaballerot/minetoy-packs@bedrock/bedrock/minetoy_iconos.mcpack
Cambiar la versión del manifest en cada cambio (los clientes la guardan en caché).
